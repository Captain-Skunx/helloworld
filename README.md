# 🐱 Python ASCII Art - Hello World!

โปรแกรมทดสอบระบบ (Test Script) สั้น ๆ บน Terminal ที่เขียนด้วยภาษา Python สำหรับแสดงข้อความ "Hello World!" ควบคู่ไปกับลายเส้นอาร์ตเวิร์กน้องแมวสุดคิ้วท์ (ASCII Art) ที่มีการตกแต่งสีสันให้สวยงามและรองรับการทำงานในทุกระบบปฏิบัติการ

---

## ✨ คุณสมบัติ (Features)
* **Colorful Terminal:** ใช้ ANSI Escape Codes ในการเปลี่ยนสีข้อความ "Hello World!" เป็นสีเขียว และตัวน้องแมวเป็นสีส้มพาสเทล
* **Cross-Platform Support:** มีการใส่คำสั่งรองรับระบบปฏิบัติการ Windows ทำให้แสดงผลสีสันได้ถูกต้อง ไม่เกิดปัญหาตัวอักษรเพี้ยนบน Command Prompt หรือ Git Bash
* **Lightweight:** โค้ดไฟล์เดียวจบ ไม่จำเป็นต้องติดตั้งไลบรารีภายนอกเพิ่มเติม (No Third-Party Dependencies)

---

## 🛠️ วิธีการติดตั้งและใช้งาน (Getting Started)

### 1. เตรียมความพร้อมก่อนเริ่มใช้งาน
เครื่องคอมพิวเตอร์ของคุณจำเป็นต้องติดตั้ง **Python 3** เรียบร้อยแล้ว
